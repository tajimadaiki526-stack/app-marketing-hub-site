Privacy Policy

最終更新 / Last updated: 2026-10-20

目的 / Purpose

App Marketing Hubは開発者本人が管理するアプリのマーケティングおよび収益状況を分析する個人用ツールです。

App Marketing Hub is a personal-use tool for analyzing the marketing and revenue performance of applications managed by its operator.

Google APIから取得する情報 / Google API Data

Google AdMob APIの読み取り専用権限により、AdMobアカウント内のアプリ識別子、関連するストア情報、日付別の推定広告収益など、アプリ単位の集計情報を取得します。公開ページへの訪問者にGoogleアカウント認証は要求しません。

With the operator's consent, the tool uses the read-only AdMob API to access app identifiers, related store metadata, and app-level aggregate advertising performance including daily estimated earnings. Visitors to this informational website do not need to sign in.

情報の利用 / Use

取得した情報は、運営アプリの業績分析、比較、レポート作成、マーケティング改善にのみ使用します。第三者への販売や広告ターゲティングには使用しません。

The data is used only for reporting, comparing the operator's apps, and improving their marketing. It is not sold or used for personalized advertising.

保存・共有・セキュリティ / Storage, Sharing & Security

取得したアプリ単位の集計情報は、アクセスを制限した非公開GitHubリポジトリに保管します。OAuth認証情報はGitHub Actionsの暗号化Secretsで管理し、公開Webページに掲載しません。運用に必要な範囲でGoogleとGitHubのサービスを利用します。

Aggregate app-level data is stored in a private access-restricted GitHub repository. OAuth credentials are protected in GitHub Actions encrypted secrets and never published on this website. Google and GitHub provide the necessary API and infrastructure services.

保存期間・削除 / Retention & Deletion

集計情報は分析に必要な期間だけ保持し、不要になったデータは削除します。Googleアカウントのアクセス許可はGoogleアカウントの「サードパーティとの接続」設定から取り消せます。許可の取り消しは今後のAPI取得を停止しますが、既に保存した集計データを自動削除するものではありません。削除に関する問い合わせは下記の問い合わせ先に連絡してください。

Aggregated information is retained only as long as needed for analysis and removed when no longer required. The Google authorization can be revoked from Google Account third-party connections; revocation prevents future API access but does not automatically delete previously stored aggregates. Contact the operator for deletion requests.

公開サイトのアクセス / Website Visitors

本公開ページには独自のアクセス解析、広告、トラッキングCookieを導入していません。ただしホスティング提供者はサービス提供に必要なアクセスログを処理する場合があります。

This public page does not intentionally deploy tracking cookies, advertising or analytics. The hosting provider may process routine access logs to operate the service.

問い合わせ / Contact

アプリのプライバシーに関するお問い合わせは、公開サイトのサポート窓口（GitHub Issues） へお願いします。個人情報や認証トークンは公開Issueに投稿しないでください。

For questions about privacy or deletion, contact the operator through the public site support channel (GitHub Issues). Do not disclose personal details, credentials, or tokens in a public issue.
