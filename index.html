App Marketing Hub

自分が運営するアプリのマーケティング状況を、安全に分析するための個人用ツールです。

A personal-use reporting tool for an independent developer to analyze marketing performance of apps they operate.

このサービスについて / Purpose

App Marketing Hubは、アプリの広告収益や利用状況を比較し、改善施策の判断を支援します。一般ユーザー向けにアカウント登録を提供するサービスではありません。

The tool brings together aggregate app-level marketing and advertising reports to support decisions about the developer's own apps. It does not offer public account registration.

Googleのデータを使う理由 / Google API Access

Google AdMob APIの読み取り専用権限を使用し、登録アプリと推定広告収益の集計データを取得します。広告設定を変更したり、Googleアカウント内のメールを読んだりすることはありません。

Google AdMob's read-only API is used to retrieve app registration information and aggregated estimated ad earnings. No ad account settings are modified, and Gmail data is not accessed.

保存と保護 / Storage & Protection

集計データはアクセス制限された非公開リポジトリに保管し、認証情報はGitHub Actionsの暗号化Secretsで管理します。サイトでは広告、トラッキングCookie、ユーザー分析ツールを使用しません。

Aggregate reports are kept in a restricted private repository. API credentials are stored in encrypted GitHub Actions secrets. This public information page uses no advertising, tracking cookies, or analytics.

プライバシーポリシー / Privacy Policy

This page contains public documentation only. No API credentials, revenue reports, or private app data are exposed here.
