## Free hosting with GitHub Pages

Under **Settings → Pages**, choose **Build and deployment → Source: Deploy from a branch**,
then select **main / (root)** and save. Once deployed, the informational site can be viewed at:

- https://tajimadaiki526-stack.github.io/app-marketing-hub-site/
- https://tajimadaiki526-stack.github.io/app-marketing-hub-site/privacy.html

A custom domain has **not** been acquired or configured; do not claim one until registration and DNS validation complete.
